Custom fields

Signed in as Add delegates Dashboard

Extra columns in a delegate CSV become custom fields. A column like food_preference or T-Shirt Size is stored with each delegate and listed here the first time it appears. New fields start hidden: choose where each one shows.

  • Scanner popup: shown to volunteers after every scan. The values are copied to every scanner phone, so keep personal details (phone numbers, medical notes) off unless volunteers need them.
  • Dashboard filter: adds a filter for the field to the delegate table.
