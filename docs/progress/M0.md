# M0 Foundation

## Gate

- `EVENTPASS_DEMO=1 go run ./cmd/eventpass serve` opens a seeded control panel.
- Magic-link login works through `/dev/mail`.
- The authorization matrix test passes for all five roles (owner, admin, staff, viewer, participant).
- CI runs lint, tests and the OpenAPI drift check.

## Scope

In:

- Repo skeleton, Apache-2.0 license, `PROGRESS.md`, ADRs.
- `cmd/eventpass`: `serve`, `keygen`, `version`. `admin add`, `check`, `migrate` and `export` need the Sheets adapter and move to M1.
- `internal/app`: env config (with `.env`), wiring, HTTP server, graceful shutdown, embedded web app.
- `internal/domain` (pure): roles and permissions, participant statuses and allowed transitions, field types and server-side validation, field visibility, pass ID generation.
- `internal/storage`: `Store` / `EventRepo` interfaces for the M0 repos (workspace settings, users, events, event roles, audit; event settings, fields, participants, checkpoints, checkpoint log), a shared contract test suite, and the `memory` adapter with the demo seed (two events, 150 participants).
- `internal/auth`: magic links (SHA-256 hash only, 15 min, single use, uniform response), encrypted session cookies with `SessionVersion`, principal resolution, permission checks.
- `internal/mail`: `Sender` interface, header sanitizing, a background send queue and the dev mail catcher behind `/dev/mail`. The MIME builder comes with SMTP in M1.
- `internal/api`: route table where every route declares its permission, error shape, CSRF header, security headers, rate limits.
- `api/openapi.yaml` and a Go test that fails when the route table and the spec drift; generated TypeScript types in `web/src/api/schema.ts` with a CI check that they are current.
- `web/`: Vite + React + TS. Control panel (login, events list, event overview, participants, staff/roles, workspace users) and portal (login, my registrations). Code-split by area.
- CI: golangci-lint, `go test`, OpenAPI drift, web lint/typecheck/test/build, Playwright e2e of the magic-link login against the demo.

Out (later milestones): Sheets adapter and setup wizard (M1), registration and passes (M1), scanning (M2), schedule and maps (M3), templates/outbox/announcements (M4).

## Risks

- The route table, permission map and OpenAPI file can drift: mitigated by the drift test and by writing the matrix's expected outcomes independently of the permission map.
- Email link scanners (Outlook Safe Links) follow links and would burn single-use tokens: mitigated by making the link open a page that POSTs the token (ADR 0003).
- Magic-link tokens live in memory, so a restart invalidates pending links. Acceptable for a single instance with 15-minute tokens (ADR 0004).
